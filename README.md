# Світло Кіровоградщини

Статичний сайт для GitHub Pages з адресним пошуком і синхронізацією з офіційним сайтом ПрАТ «Кіровоградобленерго».

## Як опублікувати

1. Створіть GitHub-репозиторій і завантажте сюди всі файли.
2. Увімкніть **Settings → Pages → Source: GitHub Actions**.
3. Зробіть `push` у `main`. Workflow сам встановить Chromium, спробує забрати свіжі дані з офіційного сайту і опублікує сайт.

Workflow запускається також за розкладом **кожні 5 хвилин**. Браузерна частина сайту перевіряє новий опублікований знімок **щохвилини** без скидання введеної адреси.

## Важливо

GitHub Pages не має власного бекенду. Тому прямий запит браузера до `kiroe.com.ua` не є основним механізмом: синхронізацію виконує GitHub Actions, а сайт отримує JSON з того самого GitHub Pages-домену. Це прибирає CORS-проблему і не вимагає API-ключів.

Синхронізатор спеціально не затирає попередній валідний знімок, якщо структура офіційного сайту тимчасово змінилася. У такому випадку в `data/official.json` зберігається попередня валідна версія та діагностика останньої спроби.
